# H-Relay

> Intelligent Event & Notification Relay

---

## 🚀 Overview

H-Relay adalah platform Event & Notification Relay yang menerima event dari berbagai sistem dan meneruskannya ke berbagai channel seperti WhatsApp, Telegram, Discord, Slack, Email, maupun Webhook.

---

## ✨ Planned Features

- Webhook Receiver
- Queue Processing
- Smart Alert
- Rule Engine
- WhatsApp Notification
- Telegram Notification
- Discord Notification
- Dashboard
- Kubernetes Deployment
- ArgoCD
- Grafana Integration
- Prometheus Integration
